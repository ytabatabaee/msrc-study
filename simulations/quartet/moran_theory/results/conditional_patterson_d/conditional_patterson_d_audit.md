# Conditional MSRC Patterson's D implementation audit

## Classification and sign conventions

For the rooted taxon order `(P1,P2,P3,O)`, the implementation uses:

| Internal split | Quartet index | Site-pattern contribution |
|---|---:|---|
| `P1,P2 | P3,O` | Q1 | species-tree topology |
| `P1,P3 | P2,O` | Q2 | BABA |
| `P1,O | P2,P3` | Q3 | ABBA |

The first coalescence identifies the two-taxon side of the unrooted split.
The interval between the first and second coalescences is the internal branch
that can carry a two-two infinite-sites mutation. Consequently,

`D_patterson = (branch_sum_Q3 - branch_sum_Q2) / (branch_sum_Q3 + branch_sum_Q2)`.

The diagnostic reported as `D_topology_q2_minus_q3` has the opposite
orientation, `(q2-q3)/(q2+q3)`. The diagnostic `D_branch_q2_minus_q3` also
has the opposite orientation to Patterson's D. This sign difference is a
labeling convention, not a contradiction in the estimator.

## History conditioning and independence

Each accepted history is generated by the existing Moran frequency simulator.
The terminal arrangement pattern `0101` is declared before simulation and is
obtained by rejection sampling the history plus terminal arrangement draw.
After acceptance, that history and sampled arrangement are held fixed while
independent genealogy calls use independent random draws. No history is
selected using its topology, branch lengths, or D value, and the simulator's
species-tree path has no interspecies gene-flow event.

The acceptance count is recorded as the number of history attempts since the
previous accepted history. It is a waiting-time diagnostic, not a plug-in
estimate of the exact pattern probability from one replicate.

## Mutation validation

The pilot mutation check uses Poisson mutations on the Q2 or Q3 internal edge,
which is exactly the branch-length expectation for ABBA/BABA under an
infinite-sites model with a shared mutation rate. It is deliberately a
feasibility check: mutations on one genealogy are linked and do not create
independent genomic replicates. The production design therefore reports
genealogy-level uncertainty and history-level variation separately. A future
sequence validation should simulate independent genealogical blocks and use
block uncertainty.

## Current evidence

The 3-history pilot gave branch-based ABBA-minus-BABA D values -0.461, -0.187,
and -0.159. The isolated 10-history × 500-genealogy convergence run gave
mean -0.193, SD 0.083, range -0.303 to -0.047; all ten estimates were
negative, and seven had a genealogy-bootstrap interval excluding zero under
the exploratory `|D| > 1.96 SE` rule. This is evidence that the conditional
effect is reproducible in this small sample, not a history-averaged estimate
or an independent-locus significance result.

The standard MSC control in that run used 5,000 genealogies and gave branch D
0.0110 with bootstrap SE 0.0258. This is consistent with zero at the pilot
scale. The production array is required to estimate the between-history
distribution and sensitivity to `rho`, persistence, population size, and
other prespecified parameters.
