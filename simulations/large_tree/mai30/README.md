# Mai30 large-tree MSRC study

This directory is reserved for the large-tree simulation study using the
authenticated Mai et al. (2017) D1 SimPhy dataset as fixed species-tree
backbones. New MSRC and ordinary MSC gene trees will be generated by the
authoritative `msrc-sim` implementation after the SimPhy demographic
parameters are recovered.

Current state:

- Mai D1 provenance is authenticated through the article, author repository,
  author project page, and Dryad DOI.
- The Dryad manifest and published SHA-256 checksums are recorded.
- The local `D1-true.tar.gz` archive is checksum-verified and the species-tree,
  command, log, parameter, and selected original-gene-tree files are extracted.
- SimPhy D1 records one global haploid effective population size per replicate
  and species-tree times in generations. The explicit mapping to `msrc-sim` is
  documented in `analysis/results/POPULATION_SIZE_MAPPING.md`.
- Ordinary MSC controls for four observed-discordance representatives passed
  the complete-tree output contract. Full forward MSRC histories remain
  computationally prohibitive at original population sizes; see
  `analysis/results/RUNTIME_BENCHMARK.md`.
- No full MSRC parameter grid has been launched.

The scaled-WF pilot is complete at `datasets/configs/mai30_msrc_pilot/`.
It uses `c=0.001`, 20 loci per independent history, 25 histories per 500-locus
collection, and suppression fractions 1.0, 0.5, and 0.1. The primary
configuration uses initial frequency 0.5; frequency 0.2 is prepared as a
sensitivity configuration. The resumable runner, output contract, ASTRAL
analysis, and preliminary figure scripts are documented in
`analysis/results/MAI30_SCALED_WF_PILOT_RESULTS.md`.

The epsilon-mixture analysis is implemented for the six matched complete
source pools from replicates 007 and 042. See
`analysis/results/MAI30_EPSILON_RESULTS.md` and
`analysis/results/MAI30_EPSILON_THRESHOLD_ANALYSIS.md`. The replicate-042
CULength saturation audit is in
`analysis/results/MAI30_BRANCH_LENGTH_AUDIT.md`. Original-scale
`wf_diffusion` configurations are prepared but not executed under
`datasets/configs/mai30_diffusion_experimental/`.

The four-replicate pilot contains 12 complete collections: 25 independent
histories × 20 loci and 500 validated gene trees per collection. The two
primary gene-tree comparisons are summarized in
`analysis/results/MAI30_MSRC_COMPARISON_RESULTS.md`. The reproducible script
`analysis/scripts/summarize_msrc_discordance.py` measures MSRC discordance
from the true species tree and compares MSRC and original Mai gene-tree
distributions without pairing independent realizations. Complete 500-tree
comparisons cover replicates 042, 007, 005, and 074.

The corrected strict RF analysis is documented in
`analysis/results/MAI30_RF_CORRECTION_REPORT.md`. It produces explicit
300-replicate matching and validation manifests, distributional RF metrics,
within-pool baselines, and corrected CSV/TSV outputs. The 300-replicate MSRC
analysis remains planned. Its 900-task manifest and resumable SLURM array are
prepared, but no production array has been launched.

Read `DATASET_AUDIT.md`, `SIMULATOR_COMPATIBILITY.md`, and
`analysis/results/MAI30_PILOT_RESULTS.md` for the current gates and results.
