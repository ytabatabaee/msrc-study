# Mai D1 dataset audit

Status: provenance authenticated; the local D1 archive is checksum-verified
against Dryad and the species-tree/log subset has been extracted.

## Source and design

The source is Mai, Sayyari, and Mirarab (2017), “Minimum Variance Rooting of
Phylogenetic Trees and Implications for Species Tree Reconstruction,” *PLOS
ONE* 12(8), e0182238, DOI
https://doi.org/10.1371/journal.pone.0182238. The authors' project page,
`esayyari/simphy-uyen` repository, and Dryad DOI `10.6076/D1RW2G` all point to
the same D1 simulation study; this is not a substituted benchmark dataset.

The authenticated D1 design has ten model-condition directories, 100
replicates per condition, and 500 gene trees per replicate. The source files
include `s_tree.trees`, `truegenetrees`, SimPhy commands and logs, parameter
tables, and analysis scripts.

The local archive is `simulations/large_tree/D1-true.tar.gz`. Its SHA-256 is
`32490467232f0fdffdbb5cc9b8aec4b591dbbab607f7a2c07a3b6ee218a63c95`, exactly
matching Dryad's published manifest. The extracted audit subset is under
`datasets/raw/`; the archive remains available for extracting selected
`truegenetrees` files.

## Recovered SimPhy model

The exact condition commands and sampled records for all 1,000 replicates are
in `datasets/processed/mai30_replicate_parameters.tsv` and
`datasets/processed/mai30_condition_summary.tsv`. They were generated by
`analysis/scripts/audit_mai30_simphy.py`, which parses the Newick trees and
cross-checks the parameter tables against the detailed logs.

Across conditions, the commands use `-rs 100`, `-rl f:500`, `-rg 1`,
`-sl f:30`, `-si f:1`, `-st ln:14.41412,1`, `-sp u:10000,1000000`, and
`-su ln:-17.27461,0.6931472`. Generation time is fixed at 1.0. The detailed
logs explicitly label `-sp` as **haploid effective population size** and
species-tree time units as **generations**. The sampled value is global within
each replicate; no branch-specific population-size table was found in the
recovered D1 files.

The five zero-outgroup conditions contain 30 leaves. The five nonzero-outgroup
conditions contain 31 leaves: 30 ingroup leaves plus the simulated outgroup.
This distinction is preserved in the audit outputs. The source condition
names encode outgroup and rate-heterogeneity settings; conversion uses the
recovered command and log values rather than labels alone.

The `parameter.log.info` files for the three zero-outgroup conditions have a
reproducible shifted-column defect because the outgroup-ratio field is absent.
The audit detects those malformed rows and recovers the values from the
corresponding detailed `log.txt`, including replicate 001. Each recovered row
records that source in its recovery note.

## Parameters requiring an explicit MSRC decision

The following items are not silently invented:

- The source does not define a separate MSRC root-extension value above the
  species-tree root. This must be an explicit MSRC modeling choice.
- Because SimPhy labels `-sp` haploid, the conversion cannot blindly apply
  `g/(2N_e)` to the logged number. The converter must state the convention used
  by `msrc-sim`; if its input is diploid, the input must be transformed so that
  its coalescent scale matches SimPhy's `1/N_haploid`.
- Original true gene trees are present in the authenticated archive and have
  been extracted for 300 no-outgroup replicate collections. Four collections
  selected by observed normalized-RF quantiles are used for MSC validation.
- SimPhy's manual identifies gene-tree branch lengths as expected substitutions
  per site, whereas species and locus branches are in generations. The
  baseline therefore reports gene-tree topology statistics and does not treat
  original gene-tree branch lengths as coalescent times.

The population mapping, root treatment, and ordinary MSC baseline are now
validated. The remaining gate is computational feasibility of original-scale
forward Wright–Fisher MSRC histories; see `analysis/results/RUNTIME_BENCHMARK.md`.
