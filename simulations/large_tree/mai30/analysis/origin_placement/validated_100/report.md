# Validated Mai30 Quartet-Reversal Experiment

The summarized run used simulator commit `bfba58d627f6f467af649cdb0b37f969349e0aab`, 275 completed history checkpoints, six rho values, and one genealogy per history/rho.

No full 30-taxon ASTRAL validation was run: the prespecified gate requires an independently supported discordant dominant quartet.

Uncorrected negative-dominant rows passing the nominal history-level interval rule: **1**; rows passing the conservative multiple-comparison gate (z=4.5): **0**.

Intervals use the forward-history unit; the multiple-comparison gate is required before calling a quartet reversal validated. Conditional rows are descriptive and are not used to infer natural pattern frequencies.


The 1,000-history expansion remains gated on these initial results and computational cost. Raw compressed forward histories are retained in the checkpoint directory and are not included in the committed summary outputs.
