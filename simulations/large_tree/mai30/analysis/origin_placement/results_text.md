# Results

The grouped backward implementation is statistically compatible with the
reference implementation in focused topology and event-invariant tests, and
was approximately 2.15x faster on a 30-taxon pilot genealogy. A small
20-history discovery run for Mai replicate 007 produced arrangement-conditioned
and marginal quartet tables for the existing, deeper, and root-adjacent
scenarios. These tables are exploratory: they do not support a statistically
validated quartet reversal.

The requested 1,000-history all-tree persistence run was not completed locally.
Long Wright--Fisher histories, especially the older-root scenario, remain the
limiting operation. No ASTRAL result was generated from an origin-placement
configuration.
## Validated A/B quartet pilot

The current run is partial. Both A and B are complete for replicate 007; the
other A/B configurations do not yet all have 100 histories. The complete 007
batch shows a higher origin-polymorphism fraction for B than A, but this is not
yet a four-tree result. One nominal negative quartet-margin row is present;
zero rows pass the conservative multiple-comparison gate. No quartet reversal
or ASTRAL bias is therefore validated.
