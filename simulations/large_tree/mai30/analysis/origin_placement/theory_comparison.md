# Theory comparison

Structural exposure is exact combinatorics: all \(\binom{30}{4}=27,405\)
quartets were enumerated for every origin scenario. Forward persistence and
terminal pattern frequencies were generated by the authoritative Wright--
Fisher simulator, with one independent history per audited scenario/tree.

The finite-(M) quartet operator in
`simulations/quartet/moran_theory/` is a four-lineage hierarchical result. It
does not provide an exact 30-taxon origin-placement theorem. Therefore this
directory does not claim exact 30-taxon quartet probabilities from that
operator. A full comparison would require either an exact induced-quartet
mapping retaining the shared frequency history or a substantially larger
direct simulator run.

No population-level quartet reversal or ASTRAL effect is inferred from the
forward-only audit. The genealogy-level discovery run was stopped because
30-taxon backward simulations were not computationally feasible locally.
