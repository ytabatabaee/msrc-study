# Model audit

The experiment uses the scaled Mai30 species trees and the authoritative
`msrc-sim` Wright--Fisher process.  The forward process has (M=2N_e) copies,
binomial generation updates, binomial daughter initialization at speciation,
and the configured neutral initial count.  The backward process uses
`rho = baseline_rate * effective_cross_arrangement_fraction`, switching at
`rho*p` and `rho*(1-p)` and finite-population same-background coalescence.

`SpeciesTree` represents the older ancestral extension as a branch whose ID is
the autogenerated root node name (for example `N29`), rather than the literal
string `ROOT`.  The scenario manifest records those actual IDs.  The
structured boundary is determined by the origin age

\[
t_{origin}=t_{branch,older}-t_{origin\_from\_branch\_start}.
\]

Scenario A retains each pilot origin. Scenario B selects the oldest non-root
internal branch subtending between 4 and (n-2) taxa and places the origin so
that approximately 50 generations of structured exposure remain when the
branch permits it. Scenario C uses the root-extension branch with an origin
50 generations before the root speciation. Scenario D doubles the root
extension and places the origin near its older end. D is a forward-persistence
stress case in the local run; its 30-taxon backward genealogy was not run.

The four trees are the existing low, intermediate, high, and extreme-ILS
pilot representatives. The scaling factor remains (c=0.001), initial
frequency is 0.5, and no selection is introduced.
