# Mai30 weak-effect mechanism report

## Conclusions

1. The three pilot switching rates produce materially different switching
   histories: roughly 31.6, 14.9, and 3.73 switches per genealogy for
   rho=0.02, 0.01, and 0.002.
2. Polymorphism persistence is branch-specific.  In replicate 007, the N8
   origin branch is polymorphic at its younger end in roughly 0.28--0.31 of
   histories across treatments. Other branches are often fixed or absent.
3. Discordant 2:2 terminal patterns are uncommon relative to uniform and 3:1
   patterns in the diagnostic panel, averaging about 0.057, 0.086, and 0.080
   for rho=0.02, 0.01, and 0.002. These values classify patterns against
   each quartet's actual induced species-tree split.
4. The current evidence supports dilution and restricted-clade exposure as
   important mechanisms. It does not support the claim that switching rates
   are effectively equal.
5. The retained pilot does not contain enough lineage-level event detail to
   quantify coalescence-before/after-switch ordering or realized switch time
   by branch. Those are explicit data limitations.
6. No parameter regime with a validated quartet reversal or systematic ASTRAL
   change has been demonstrated. The expanded rate grid is prepared but not
   executed.

## Decision

Do not change the Mai30 production parameters or launch the 300-replicate
experiment based on the current evidence. First run the planned mechanistic
rate experiment on a small fixed set of low, intermediate, high, and extreme
ILS trees, preferably with optional backward event-detail recording. If the
expanded grid still produces only small induced-quartet shifts, the current
Mai parameterization is testing a restricted internal rearrangement whose
effect is naturally weak at the whole-tree level.
