# Methods

We audited the 12 completed Mai30 pilot collections using the retained
per-history frequency records, terminal arrangement states, genealogy-block
switch counts, and gene trees.  Each collection has 25 independent forward
histories and 20 loci per history.  The effective intensities were computed as
`rho=0.02*kappa`.

For each retained history we summarized switch counts per genealogy, terminal
patterns on a deterministic panel of 12 four-taxon subsets, and polymorphism
at branch boundaries.  Integrated hazard columns are forward-history
quantities `rho*integral(p(t)dt)` and
`rho*integral((1-p(t))dt)`, not realized lineage switch counts.

Quartet topology was classified by descendant splits using the same Newick
split convention as the existing Mai analyses.  Conditional probabilities
were estimated within terminal arrangement patterns; marginal decompositions
were computed from the same joint counts.  The 30-taxon ASTRAL table is copied
from the completed pilot and is not a result of the unexecuted rate grid.
