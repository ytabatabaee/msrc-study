# Mai30 staged branch-length audit

The earlier suppression-effect branch table compared ASTRAL `CULength` output
with the raw SimPhy species tree.  SimPhy branch lengths are in generations;
the MSRC pilot scales both generations and effective population size by
`c=0.001`.  That mismatch inflated every true branch length by exactly 1,000.

The corrected pipeline uses the validated scaled species tree written under
`datasets/processed/mai30_scaled_wf_runs/.../history_000/species_tree.nwk` and
computes

```text
true_CU = scaled_species_tree_length / (2 * N_scaled).
```

This is the same conversion used by the pilot ASTRAL audit and by
`run_production_astral.py`.  A branch is compared only when its canonical
internal bipartition occurs in both trees.  Incorrect ASTRAL splits are kept in
topology tables and are excluded from branch-length error summaries.

The staged-production table is generated by
`scripts/audit_branch_lengths.py` after staged collections and ASTRAL outputs
exist.  It records one row per matching split with signed error, absolute
error, and relative error.  Summary statistics must be calculated from those
rows; no post-hoc rescaling is applied.

The existing four-replicate pilot audit provides the regression reference:
replicate 042 true internal branch lengths are approximately 1.88--136.09
coalescent units.  Values near 1,000 times that range indicate that raw
SimPhy-generation lengths were used by mistake.

The four-replicate pilot branch table and its bootstrap were regenerated with
the corrected source-tree selection.  The remaining variation is finite-tree
ASTRAL estimation error and saturation on long internal branches, rather than
the former unit-conversion error.
