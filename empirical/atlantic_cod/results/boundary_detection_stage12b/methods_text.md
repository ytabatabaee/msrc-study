# Methods

Stage 12b imports the frozen Stage-12 feature join and reproduces its primary fits without writing to Stage-12 outputs. Model A is the Stage-12 joint least-squares interval objective. Model B uses robust median/MAD standardization, two independent topology coordinates, and one A(w) coordinate with equal modality contribution. Model C uses robust D(w) and A(w) coordinates and permits only candidates whose inside-minus-outside shifts are positive in both coordinates. This direction is a prespecified biological hypothesis about arrangement-associated topology and divergence contrasts under recombination suppression. Model D combines separate one-dimensional standardized topology and time profile improvements with fixed equal weights. All models retain the no-change option, three-window minimum segment, and BIC-like penalty.

For each published local tree, arrangement-blind summaries include mean, median, and variance of all population-tip patristic distances, mean internal branch length, total branch length, tree height, and total-length-normalized distance/height summaries. These are summaries of the published SNAPP population-tree / local-tree representation and are not interpreted as realized lineage coalescence times.

Detection significance is based on the maximum scanned interval score under 199 deterministic permutations of contiguous five-window blocks. Holm correction is applied across linkage groups within each method. Boundary stability uses leave-one-contiguous-block-out perturbations; these ranges are descriptive. Known inversion coordinates are read only for post-fit evaluation and are never used to choose model weights, penalties, or intervals.
