# Patterson's D methods

Patterson's D was calculated directly from unphased diploid nucleotide genotypes using population allele frequencies and a complete, fixed-outgroup ancestral allele. For each site, ABBA and BABA contributions were `(1-p1)*p2*p3` and `p1*(1-p2)*p3`; contributions were summed before taking the ratio. Heterozygotes contribute allele frequencies, and partially missing outgroup diploids are excluded. Multiallelic, unsuitable-missingness, insufficient-callability, polymorphic-outgroup, and MAC-failing sites are counted by exclusion reason. The primary filter uses no MAC threshold; MAC >= 2 is a sensitivity analysis matching Stage 2R. The full workflow uses 500-kb, 1-Mb, and 2-Mb physically contiguous block jackknives; the eight-window pilot is descriptive only.
