# Anopheles Stage 12 distance extension

Reproduce from the repository root with:

```sh
python empirical/anopheles_2la/scripts/12_spatial_distance_track.py
python empirical/anopheles_2la/scripts/13_boundary_distance_validation.py
python -m pytest -q empirical/anopheles_2la/tests/test_stage12_distance.py
```

The tree branches are NJ patristic substitution-distance units. The primary
arrangement contrast uses only within-species homozygous 2La and 2L+a
haplotypes; heterokaryotypes remain in arrangement-blind summaries.
