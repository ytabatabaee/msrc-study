# Figure caption

**Chromosome-4 mixture sensitivity of the 48-taxon ASTRAL-IV species tree.** (A) Unrooted Robinson–Foulds distance of each inferred tree from the non-chromosome-4 reference and from the full-data J48_T0 reference. Points are the 13 measured with-replacement mixtures; the shaded interval marks the coarse grid between epsilon = 0.05 and 0.10 in which the complete J48_T0 topology first appears. The dashed line is the chromosome-4 fraction in the stage-4d locus manifest, 6262/63430, shown as a genomic sampling reference rather than as a fitted threshold. (B) Presence of each of the six exact reference-specific unrooted splits. T0 and N denote the corresponding reference split; blank cells contain neither reference split and may include novel splits. (C) ASTRAL localPP for the inferred branch matching each reference-specific split, with gaps when that exact split is absent. These values are branch-local annotations and are not fixed-topology quartet scores. Each epsilon represents a separate 62,945-record with-replacement mixture of chromosome-4 and non-chromosome-4 gene-tree records; it is not a directly measured fraction of the genome experiencing suppressed recombination.
