# Methods

Ten deterministic representative sets were evaluated, including replicate zero copied from the frozen Stage 11B result. The other sets substitute taxa present in the original 63K reference phylogeny and source gene-tree file while preserving the induced four-taxon `q2` topology. The alternatives were Columbina, Patagioenas, and Caloenas for the pigeon/dove role; Podiceps and Podilymbus for the flamingo-associated role; Corythaixoides for the turaco role; and Coturnix, Phasianus, and Meleagris for the galliform outgroup role. Each selected set was fixed across all genomic windows. Source trees were pruned locus by locus, branch lengths were retained, missing taxa were excluded, and trees were sorted by the original chromosome-4 coordinates.

Official Phlag v0.2.0 was executed without modification. A run was valid only when its process output contained complete state and posterior sequences with exactly the manifest length and finite posterior probabilities in `[0,1]`. State-1 windows were merged with the frozen 250-kb physical-gap rule. The matched detector is the existing Stage 11B categorical four-taxon detector, applied independently to the same eligible loci with its frozen scaling and penalty. Structural candidate regions were read only during evaluation and plotting.
