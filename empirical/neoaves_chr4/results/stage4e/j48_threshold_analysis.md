# J48 quartet mixture and threshold analysis

The quartet summary uses the existing `normalized_QQS` window summary, averaged across available loci. It is not ASTRAL branch-quartet frequency and does not establish an MSRC mechanism.

The locus manifest contains 63430 loci, including 6262 chromosome-4 loci (0.098723). This sampled-locus fraction is reported separately from the mixture weight epsilon.

For each focal quartet, `Q(epsilon)=(1-epsilon)Q_B+epsilon Q_R`; pairwise crossover values are in `j48_quartet_mixture.tsv`. A valid interior pairwise equality is only a candidate quartet crossover: the third topology must be checked, and it is not a species-tree transition.

The current local deliverables do not claim an empirical full-tree transition. The coarse mixture grid and matched controls are prepared for Bridges-2.
