# Methods

The primary detector uses native Columbea locus-level D2 and D3 values, robust median/IQR/MAD/SD-floor scaling, a shared-background single-interval least-squares scan, minimum three loci per segment, a no-detection option, and a fixed penalty. A second configuration adds Stage 9 B_observed as additional information. Phlag is the unchanged upstream v0.2.0 implementation. Published-result comparison was unavailable because no per-locus published Phlag prediction file was present locally.
