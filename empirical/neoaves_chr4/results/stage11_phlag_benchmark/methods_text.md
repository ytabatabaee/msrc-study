# Methods

Phlag was run using the upstream v0.2.0 executable and fixed representatives Columba_livia, Phoenicopterus_ruber, Tauraco_erythrolophus, and Gallus_gallus. Local trees were pruned individually, ordered by source-defined genomic coordinates, and paired with a repository-relative manifest. State 1 is treated as anomalous only after validating the upstream output convention. Anomalous runs were merged only when the physical gap was at most 250 kb; gap sensitivity is reported. The matched detector uses the same categorical four-taxon tree observations as two topology-indicator coordinates and is explicitly distinct from the original multi-taxon topology and topology-plus-B detectors. Structural candidate regions are used only for post-fit evaluation.
