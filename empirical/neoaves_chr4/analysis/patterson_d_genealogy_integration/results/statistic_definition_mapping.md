# Statistic-definition and sign mapping

For N61 the frozen roles are P1=C1=`Tauraco_erythrolophus`, P2=C2=`Columba_livia`, P3=S=`Ciconia_maguari`, and O=`Gallus_gallus`. The existing QQS definitions are q1=(C1,C2)|(S,O), q2=(C1,S)|(C2,O), and q3=(C2,S)|(C1,O).

With outgroup polarization, ABBA is A/B/B/A and supports the P2-P3 split, which is q3. BABA is B/A/B/A and supports the P1-P3 split, which is q2. Therefore negative nucleotide Patterson D means BABA>ABBA and is expected to correspond to positive q2-q3, not to positive q2-q1. The existing topology-shift statistic is q2-q1 and is a different contrast.

Gallus is an independently external galliform reference relative to the three Neoaves ingroup roles, so the rooted quartet is biologically defensible for this exploratory comparison. All branch lengths are ML substitution units, not coalescence times; B_observed is an arrangement-blind mean patristic distance over observed taxa.

The PNAS intervals are GalGal4 window-start intervals. The Stiller/Stage-4D locus axis is GalGal6. The repository audit records approximate GalGal6 counterparts but no nucleotide-resolution lift was applied; all cross-track comparisons therefore retain the repository's validated published-predicate mask and explicitly preserve this assembly caveat.
