# House-mouse Stage 4 distance extension

Reproduce from the repository root with:

```sh
python empirical/house_mouse_t_complex/scripts/04_spatial_distance_track.py
python empirical/house_mouse_t_complex/scripts/05_boundary_distance_validation.py
python -m pytest -q empirical/house_mouse_t_complex/tests/test_stage4_distance.py
```

The branches are published IQ-TREE/ML substitution-distance units. The t versus
standard contrast is restricted to mapped within-subspecies groups; M. spretus
is retained only in arrangement-blind summaries. The multi-interval scan is
reported separately because four frozen t-complex intervals are present.
