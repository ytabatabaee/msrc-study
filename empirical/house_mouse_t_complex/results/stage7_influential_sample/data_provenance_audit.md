# Data provenance audit

Trees: `data/house_mouse_t_complex/processed/house_mouse_t_complex_ml_5kb.tre`; 4,046 metadata-matched ML trees. Branch lengths are published ML patristic substitution units. The primary B(w) uses all mapped non-*M. spretus* pairs; the sensitivity removes `Mmd_FRA4_18B.variant` from every recalculated numerator and denominator. ALL_TIPS topology uses the frozen quartet definitions; leave-one-out support removes the same tree tip from its status group. Alignments, SNP counts, and full per-window inference settings are unavailable.
