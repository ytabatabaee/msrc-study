# House mouse — phase-aware SNP-panel results complete; gVCF callability integration open — data audit

Date: 2026-11-20. Existing MSRC gene-tree coordinates and sample manifests have been audited first. This package now includes clearly labeled SNP-panel analyses where verified genotype calls are available. None of the reported SNP-panel quantities is per callable base: all-sites denominators remain unavailable, so per-callable-nucleotide FST, dXY and pi are not claimed.

## Dataset audit

The public Harr et al. AllMouse PASS VCF (67 samples) is indexed and was queried over all 4,046 existing 5-kb mm10/GRCm38 chr17 tree windows (5,000,000–37,055,000), with 1,044,870 biallelic SNP records in the retained windows. A follow-up indexed query scanned full chr17 [0, 94,987,271) in 18,998 5-kb bins (5,086,154 biallelic PASS SNP records); the VCF is not tree-limited to 40 Mb. Frozen within-subspecies designs are Mmd 4 t/12 standard, Mmm 8/13, and Mmc 3/7. Diploid carriers were not counted as pure t: homozygous carrier genotypes contribute their observed allele; heterozygous carriers contribute a t allele only when exactly one allele is absent from all same-subspecies standards. Ambiguous or missing carrier calls are masked. The sitewise pseudo-t analysis averages 3.91, 7.70 and 2.90 reconstructed t alleles per site respectively; carrier call ambiguity/missing rates are 4.9%, 6.3% and 8.8% conditional on standard calls.

All three designs have 3,824 inside and 222 outside windows overlapping the four validated mm10 inversion intervals, except Mmm Hudson FST has one undefined window because its summed dXY denominator is zero. Inside-minus-outside SNP-panel FST differences are +0.2013 (Mmd; 95% 500-kb block interval −0.3176 to +0.4936), +0.3628 (Mmm; −0.2039 to +0.6557), and +0.2556 (Mmc; −0.1478 to +0.4804). dXY differences are +0.0181, +0.0443, and +0.0116, with all intervals including zero. pi_t and pi_standard contrasts are mixed and all block intervals include zero. The positive differentiation direction is compatible with t/standard divergence, but uncertainty is broad (only four outside 500-kb blocks) and all values are per observed PASS SNP.

The public source also contains a per-sample `vcf/GVCF/` directory with invariant reference blocks; a test query verified GT/DP/GQ/MIN_DP fields. These gVCFs were not intersected across all 47 frozen samples and all tree windows, so a callable-base denominator is not yet produced. A 5–37 Mb indexed query against one gVCF traversed ~1.9 GB of compressed data before manual cancellation; scaling a shared-mask pass to 47 samples is a substantial I/O follow-up. The source exists, but its common mask is not yet computed. The PASS VCF has no invariant records and does not link carrier phase across sites. Mmd, Mmm and Mmc are analyzed separately to control broad subspecies structure, but geographic structure remains within Mmd and Mmm.

See `empirical/house_mouse_t_complex/window_diversity/results/mouse_results_report.md`, scripts `empirical/house_mouse_t_complex/window_diversity/scripts/analyze_t_pseudohap_snp_panel.py` and `empirical/house_mouse_t_complex/window_diversity/scripts/analyze_full_chr17_snp_panel.py`, the per-window/join/correlation tables, three subspecies-specific tree-matched figures, and full-chr17 tracks. The full chromosome extends beyond local trees, so no tree-track correlation is asserted outside 5.0–37.055 Mb. It remains a PASS SNP panel without invariant sites; common gVCF callability masks are not yet computed.

## Estimators and shared limitations

For each SNP panel, `pi = n/(n-1) * (1 - sum(p_k^2))`, `dXY = 1 - sum(p_Xk*p_Yk)`, and Hudson FST is `sum[dXY - (pi_X + pi_Y)/2] / sum[dXY]` over observed SNPs in a window. Per-window pi and dXY are means over retained polymorphic records. Because sources lack invariant callable sequence, these are conditional per-observed-SNP statistics; SNP-only denominators are never presented as callable genome lengths. Window tracks are joined by the existing native tree-window IDs/coordinates. Suppressed-region boundaries are indicated from each system's existing source annotations. Spatial uncertainty uses physical block resampling rather than treating adjacent windows as independent; contrasts remain descriptive and do not replace a spatial-null hypothesis test.

All reproducible scripts, per-window outputs, joined track-correlation tables, dataset-specific reports and figures are in this directory. Next steps are: (1) obtain/reconcile Dryad all-sites L10 data for a verified 10-vs-12 callable-base analysis; (2) recover the published independent fire-ant 8+8 VCF or callable data and validate the local 78-vs-30 cohort result at read level; (3) reconcile mouse gVCF reference blocks across the frozen samples, compute common per-window callable lengths, and repeat geographic sensitivity analyses. Do not describe the present SNP-panel values as absolute nucleotide-diversity estimates.
