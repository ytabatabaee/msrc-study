# Matched-taxon Phlag methods

Local trees were pruned to one eligible individual or haplotype per reference taxon, with the same representative used in every window. No inversion coordinates were used for sampling. Trees were renamed to unique reference labels and checked for exact taxon-set equality. The original Phlag command and default parameters were used. The Phlag basal bifurcation was allowed to be collapsed by the upstream implementation; its removed basal child was not passed as a focal edge.
