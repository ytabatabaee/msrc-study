# Empirical Tajima's D

Run the shared tests with `PYTHONPATH=empirical/analysis/tajimas_d python3 -m unittest discover -s empirical/analysis/tajimas_d/tests -v`. Neurospora output is reproducible with `python3 empirical/neurospora/analysis/tajima_d/scripts/run_neurospora.py`; summary feasibility graphics are regenerated by `python3 empirical/analysis/tajimas_d/scripts/make_summary.py`.

Read `results/analysis_report.md` and `results/dataset_feasibility.tsv` before interpreting any dataset. The Neurospora panel is variant-only, so reported D values are conditional on the deposited panel and do not provide per-callable-base diversity. Other datasets without verified site records are explicitly withheld.
